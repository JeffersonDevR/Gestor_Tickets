
# GESTOR DE TICKETS PARA HOTEL

Sofware modularizado para gestionar tickets de una hotel.
La finalidad es tener un software funcional que pueda gestionar tickets, crear reservas, cancelar reservas y gestionar todo el proceso de pagos y reembolsos.


Politicas que El HOTEL tiene:

Reembolsos: si el cliente quiere reembolsar 1 dia antes de empezar la reserva, se le dara el reembolso hasta 50% del precio total de la reserva.
Si ya paso el tiempo estimado (2 dias), se podra reembolsar o no dependiendo del cliente.
